# Corporate Default Risk Model
Это репозиторий с обезличенными данными где выполняется один из этапов построения модели для кредитного рейтинга по методологии НРА.

По пяти финансовым показателям было необходимо построить модель оценки вероятности дефолта компании с помощью логистической регрессии. В рамках работы я исследовал данные и выбросы, проверил факторы на дискриминационную способность и мультиколлинеарность, провёл отбор признаков, оценил коэффициенты модели и их статистическую значимость, а также рассчитал вероятность дефолта для каждого наблюдения.

Дополнительно я провёл кросс-валидацию модели и оценил её качество по AUC, Gini и KS.
